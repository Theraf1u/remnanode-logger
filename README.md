# Remnanode Access Log Patcher 🛠️

Идемпотентный Python-скрипт для автоматической настройки проброса и сохранения логов подключений на нодах [Remnanode](https://github.com/remnawave/node).

---

## ⚠️ Важное примечание о совместимости

Скрипт проверялся и тестировался **исключительно** на нодах, развёрнутых с помощью скрипта автоматизации от **eGamesAPI**:
👉 **[eGamesAPI/remnawave-reverse-proxy](https://github.com/eGamesAPI/remnawave-reverse-proxy)**

> **Дисклеймер:**  
> Репозиторий `remnawave-reverse-proxy` является учебным примером для изучения NGINX, реверс-прокси и основ сетевой безопасности. Вы используете эти инструменты **на свой страх и риск**. Если ноды были установлены другим кастомным способом, структура `docker-compose.yml` может отличаться, и корректность работы не гарантируется.

---

## 📖 Предыстория и назначение

При использовании панели управления **[Remnawave Admin](https://github.com/Case211/remnawave-admin)** (панель управления и Telegram-бот поверх Remnawave: анти-абуз, почта, мониторинг) одной из ключевых возможностей является **Гео-карта подключений пользователей** и **детальная аналитика трафика**.

Чтобы панель и агенты могли строить карту подключений, анализировать сессии и отслеживать пользователей, требуется сбор `access.log` с каждой вашей ноды (`remnanode`).

По умолчанию в конфигурациях, создаваемых инсталлятором `remnawave-reverse-proxy`, монтирование файла логов на хост-систему отсутствует. Этот скрипт автоматизирует процесс настройки логов: он создает нужную директорию, выставляет правильные права доступа и аккуратно вносит изменения в конфигурацию Docker Compose **без нарушения синтаксиса YAML**.

---

## ✨ Что делает скрипт

1. **Подготовка файловой системы**: Создаёт директорию `/var/log/remnanode` и файл `access.log` с правами доступа `755` (для папки) и `664` (для файла).
2. **Безопасное редактирование `docker-compose.yml`**:
   * Находит сервис `remnanode` и добавляет проброс volume (`- /var/log/remnanode:/var/log/remnanode:rw`) с точным соблюдением 8-пробельных отступов.
   * Создаёт бэкап файла в `/opt/remnanode/docker-compose.yml.bak` перед изменением.
   * Удаляет невидимые спецсимволы (типа `NBSP` / `\xa0`), которые часто попадают в файл при копировании и ломают YAML-парсеры.
3. **Валидация синтаксиса**: Перед перезапуском выполняет `docker compose config`. В случае ошибки синтаксиса мгновенно откатывает файл из бэкапа.
4. **Безопасный перезапуск**: Выполняет `docker compose down && docker compose up -d` только при наличии изменений.
5. **Идемпотентность**: Безопасен для повторного запуска — проверяет наличие прописанного volume и не плодит дубли.
